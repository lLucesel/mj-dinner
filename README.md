# 🍱 mj-dinner (식단 추천 및 영양소 관리 웹 서비스)

Python FastAPI와 MySQL을 활용하여 주간 식단을 관리하고 영양소를 자동 계산해주는 웹 애플리케이션입니다.

## 🛠 Tech Stack
- **Backend**: Python, FastAPI
- **Database**: MySQL
- **Frontend**: Jinja2 Templates, HTML/CSS
- **DevOps & Tools**: AWS, Git/GitHub

## 📌 주요 기능
1. **메인 식단 추천**: DB 기반 무작위 메뉴 추천
2. **주간 영양소 자동 연산**: 일별/주간 총 칼로리, 탄수화물, 단백질, 비타민 합계 자동 계산
3. **레시피 관리**: 음식 검색 및 신규 레시피/영양 정보 등록
4. **Todo 관리**: 식단 관련 할 일 목록 C.R.U.D 기능
